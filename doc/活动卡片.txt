事件卡片不要采用普通 FullCalendar 默认 event bar。

每个事件应该像一张小型 Editorial Card。

例如：

┌─────────────────────────┐
│ 09.07                   │
│                         │
│ 🎤 SOLO DEBUT SHOWCASE  │
│                         │
│ 19:00 KST               │
│ Seoul                   │
│                         │
│ CONFIRMED               │
└─────────────────────────┘

卡片具有：
- 极细边框
- 微妙圆角
- 大量留白
- 清晰的标题层级
- 小型分类标签
- 时间与地点信息
- hover 微动画

不要使用强烈阴影。

不要做成电商商品卡片。

不要做成后台 Tag。
